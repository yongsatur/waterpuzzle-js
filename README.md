# Water Puzzle

**Water Puzzle** — это классическая логическая игра-головоломка, реализованная на чистом JavaScript, HTML и CSS. 

## Суть игры

Перед вами несколько колб с водой разного цвета. Ваша задача — **переливать воду** между стаканами так, чтобы собрать в каждом стакане воду только одного цвета. 
Игра считается выигранной, когда все стаканы заполнены одноцветной жидкостью.

> Продумывайте ходы наперед! Неправильное переливание может завести в тупик.

## Особенности

$`\color{yellow}*`$ **Простое управление**: кликните по стакану, чтобы выбрать его, затем кликните по другому, чтобы перелить воду;<br>
$`\color{yellow}*`$ **Визуальная анимация**: плавное переливание жидкости;<br>
$`\color{yellow}*`$ **Проверка победы**: автоматическое определение завершения игры;<br>
$`\color{yellow}*`$ **Сброс прогресса**: возможность начать уровень заново;<br>
$`\color{yellow}*`$ **Адаптивный интерфейс**: игра корректно отображается на разных устройствах.

## Игровой процесс

$`\color{yellow}*`$ **Кликните** по первому стакану, из которого хотите перелить воду (он будет выден);<br>
$`\color{yellow}*`$ **Кликните** по второму стакану, куда хотите перелить воду;<br>
$`\color{yellow}*`$ Вода перельётся, если верхний слой воды в первом стакане совпадает по цвету с верхним слоем во втором (или второй стакан пуст) и во втором стакане есть свободное место;<br>
$`\color{yellow}*`$ **Цель**: собрать в каждом стакане слои воды одного цвета.
