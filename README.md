# Water Puzzle

**Water Puzzle** — это классическая логическая игра-головоломка, реализованная на чистом JavaScript, HTML и CSS. 

## Суть игры

Перед вами несколько колб с водой разного цвета. Ваша задача — **переливать воду** между стаканами так, чтобы собрать в каждом стакане воду только одного цвета. 
Игра считается выигранной, когда все стаканы заполнены одноцветной жидкостью.

> Продумывайте ходы наперед! Неправильное переливание может завести в тупик.

## Особенности

- **Простое управление**: кликните по стакану, чтобы выбрать его, затем кликните по другому, чтобы перелить воду;
- **Визуальная анимация**: плавное переливание жидкости;
- **Проверка победы**: автоматическое определение завершения игры;
- **Сброс прогресса**: возможность начать уровень заново;
- **Адаптивный интерфейс**: игра корректно отображается на разных устройствах.

## Игровой процесс

1. **Кликните** по первому стакану, из которого хотите перелить воду (он будет выден);
2. **Кликните** по второму стакану, куда хотите перелить воду;
3. Вода перельётся, если:
   - Верхний слой воды в первом стакане совпадает по цвету с верхним слоем во втором (или второй стакан пуст);
   - Во втором стакане есть свободное место;
4. **Цель**: собрать в каждом стакане слои воды одного цвета.
